Try the demo

An interactive simulation that runs only in your browser: no account, no data sent. For the real app use the “Open the app” button.

Simulated demo: messages stay on your device. AES-GCM encryption is real, but contacts and replies are fake.

What to try

  1. Log in with username demo and password 1111 (personal profile) or with the biometric button.
  2. Open a chat and send a message with a 30-second timer: it self-destructs.
  3. Turn on “Server view” to see how an encrypted message looks.
  4. Hide a chat from the menu, then type 7777 in search to bring it back.
  5. Lock and log back in with username demo and password 2222: you will only see the cover profile.

Then try the Vault

  1. After logging in, tap Vault at the bottom.
  2. In Files add a file and show how someone stealing the disk would see it: only encrypted data.
  3. In Send create a one-time P2P link and watch the file arrive without touching the server.
  4. In View once send a message that self-destructs after reading, then switch on the checks in Security.
