Essayez la démo

Une simulation interactive qui fonctionne uniquement dans votre navigateur : aucun compte, aucune donnée envoyée. Pour la vraie application, utilisez le bouton « Ouvrir l'application ».

Démo simulée : les messages restent sur votre appareil. Le chiffrement AES-GCM est réel, mais les contacts et les réponses sont fictifs.

À essayer

  1. Connectez-vous avec l'identifiant demo et le mot de passe 1111 (profil personnel) ou avec le bouton biométrique.
  2. Ouvrez un chat et envoyez un message avec un minuteur de 30 secondes : il s'autodétruit.
  3. Activez « Vue du serveur » pour voir à quoi ressemble un message chiffré.
  4. Masquez un chat depuis le menu, puis tapez 7777 dans la recherche pour le retrouver.
  5. Verrouillez puis reconnectez-vous avec l'identifiant demo et le mot de passe 2222 : vous ne verrez que le profil de couverture.
