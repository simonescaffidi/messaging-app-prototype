功能原型

由密码决定打开哪个资料的聊天应用

无需手机号。输入用户名和密码：密码决定打开哪个个人资料。隐藏聊天、伪装资料、自毁消息。

你可以做什么

🔑

用户名 + 密码登录

先输入用户名，再输入密码：同一用户名，不同密码，打开不同资料。没有选择界面。

🪪

多个资料

同一设备上可有多个资料，每个资料拥有独立的联系人、聊天和设置。

🙈

隐藏聊天

把对话从主列表中隐藏。只有在搜索框输入秘密组合后才会重新出现。

🎭

伪装资料

创建一个无害的资料，以备检查时展示，不留下存在其他资料的任何线索。

💣

限时消息

发送在 30 秒、5 分钟或 1 小时后自毁的消息。

📵

无需手机号

通过邮箱注册，公开 ID 与邮箱地址分离：你的邮箱永远不会被他人看到。

🔐

真正的端到端加密

每条消息在发出前都会在浏览器中用 ECDH（P-256）+ 256 位 AES-GCM 加密：服务器只能看到密文，绝不会看到明文内容。

🫆

生物识别解锁

通过真正的 WebAuthn/FIDO2 使用 Face ID、Touch ID、Android 指纹或 Windows Hello：任何生物识别数据都不会离开你的设备。

🌍

11 种语言

应用和网站提供意大利语、英语、西班牙语、法语、德语、葡萄牙语、阿拉伯语、中文、印地语、俄语和日语版本。

不止是聊天：你的数字保险库

Securmy 不止于通讯。你保存或分享的一切都在设备上加密，使用保护聊天的同一个保险库。

🗄️

文件保险库

隐藏并保护文档、照片和文件：在设备上用 AES-256 加密，只有你的密码或生物识别才能打开。

🔗

链接点对点传输

文件直接从一台设备传到另一台，全程加密，不存放在服务器上。一次性链接，到期失效。

🧼

清理元数据

分享照片前，移除 GPS 位置、相机型号等隐藏数据。

🔑

密码管理器

把账号信息存入保险库，生成强密码并复制：剪贴板 20 秒后自动清空。

📝

加密笔记

私密笔记在设备上加密，绝不发送到任何服务器。

👁️

阅后即焚消息

收件人只能打开一次：几秒后便从服务器和对方设备上删除。

📞

加密语音和视频通话

在两台设备之间直连（DTLS-SRTP），并提供可口头核对的验证码以防窃听。

🔢

两步验证

任意验证器应用生成 TOTP 验证码：即使有人得知你的密码也无法登录。

💾

加密备份

将文件、笔记和密码导出为单个归档，由只有你知道的口令加密。

🚨

安全检查与紧急清除

评分告诉你哪里该改进；遇到危险时，轻点一下即可清除设备上的密钥、文件和密码。

☁️

加密同步（付费）

通过空间套餐（每月 5、25 或 100 GB）在多台设备间同步保险库。服务器只保存已加密的数据，密钥始终留在你的设备上。没有套餐时，一切仅保存在本地。

🛰️

中继保护 IP

借助加密中继（TURN），你可以在通话和 P2P 传输时隐藏 IP 地址，在限制严格的网络中也能使用。

安全与隐私：应用的核心

我们不只说“已加密”。下面具体说明是什么在保护你的对话。

🔄

每条消息一把新密钥

每条消息都有一次性密钥（前向保密），读后即删除。即使有人拿到你的密钥，也无法解密过去的消息。

🗝️

用你的密码加密的保险库

私钥和已读消息在设备上用你的密码加密（PBKDF2 + AES-GCM）：没有密码就无法读取。

🔍

密钥验证与防窃听提醒

与联系人当面或语音核对安全号码。若对方密钥变化，应用会提醒并在你确认前阻止发送。

🙈

“看不见”的服务器

服务器只保存密文。邮箱和用户名在数据库中加密存放；密码只保存哈希（scrypt）。

🛡️

防御登录攻击

按 IP 和用户名限制尝试次数，会话可撤销，修改密码时关闭其他会话。

🫆

生物识别不离开设备

使用 WebAuthn/FIDO2，服务器只收到通行密钥的公钥：生物特征数据永远不会离开你的手机或电脑。

如何运作

注册

邮箱、用户名和密码：你会获得一个公开ID和一个秘密组合码。请妥善保存，之后不会再显示。

使用用户名和密码登录

每次打开应用时输入用户名和密码，对应的个人资料会自动打开。

添加联系人

通过对方的公开 ID 搜索，并开始实时聊天。

按需隐藏

在搜索栏输入秘密组合，需要时即可显示隐藏聊天。

Tor 网络

服务可以以 .onion 地址提供：安装文件已就绪（自行托管），按需启用。Tor Browser 会禁用 WebRTC，因此 P2P 传输和通话无法通过 Tor 使用；消息、保险库和同步可以。

📱

iOS 和 Android 应用

带生物识别解锁的原生应用，上架应用商店，安全与隐私保障与网站一致。

它是什么，不是什么

这是一个可运行的原型，并非成品，但安全是真实的：每条消息有一把读后即删的新密钥（前向保密），私钥存放在用你的密码加密的保险库中，你可以用安全号码验证联系人身份，并在其密钥变化时收到警告。生物识别解锁使用真实的 WebAuthn/FIDO2。仍有已知限制，已在用户手册中坦率说明（元数据对服务器可见、历史绑定设备、仅能通过邮箱找回）。它尚不适用于极高风险的对话。

iOS 和 Android 原生应用

原生应用的基础框架（Expo/React Native，带系统级生物识别锁）已在项目代码中就绪。要发布到 App Store 和 Google Play，需要开发者账户凭据（Apple Developer Program 和 Google Play Console）：在关联之前，应用仍以网页应用形式提供，可在任何手机浏览器中使用，并可通过“添加到主屏幕”安装为应用。
