Без номера телефона

Настоящее сквозное шифрование

Каждое сообщение шифруется в браузере с помощью ECDH (P-256) + 256-битного AES-GCM до отправки: сервер видит только шифртекст, но не содержимое.

🫆

Биометрическая разблокировка

Face ID, Touch ID, отпечаток Android или Windows Hello через настоящий WebAuthn/FIDO2: биометрические данные никогда не покидают ваше устройство.

Как это работает

Зарегистрируйтесь

E-mail и имя пользователя: вы получите код доступа, публичный ID и секретную комбинацию. Сохраните их — повторно они не показываются.

Войдите по коду

При каждом открытии приложения вводите код: нужный профиль откроется автоматически.

Добавьте контакты

Найдите человека по его публичному ID и начните общаться в реальном времени.

Скрывайте что хотите

Введите секретную комбинацию в строке поиска, чтобы показать скрытые чаты, когда это нужно.

Что это и чем не является

Это рабочий прототип, а не готовый продукт. Сообщения защищены сквозным шифрованием (ECDH P-256 + 256-битный AES-GCM, получение ключей через HKDF-SHA256): сервер никогда не видит открытый текст. Биометрическая разблокировка использует настоящий WebAuthn/FIDO2. Остаются известные ограничения, прямо описанные в руководстве пользователя: пока нет ratchet с прямой секретностью «как в Signal», нет внеполосной проверки публичных ключей (поэтому теоретически вредоносный сервер мог бы их подменить), закрытый ключ хранится в браузере без аппаратного защищённого анклава, а отправка настоящих e-mail для восстановления аккаунта ещё не подключена. Подходит, чтобы попробовать работу с настоящей, но не «государственной» защитой — пока не для переписки с очень высоким риском.

Нативные приложения для iOS и Android

Основа нативного приложения (Expo/React Native с системной биометрической блокировкой) готова в коде проекта. Для публикации в App Store и Google Play нужны данные аккаунтов разработчика (Apple Developer Program и Google Play Console): пока они не подключены, приложение остаётся доступным как веб-приложение, работает в любом мобильном браузере и уже устанавливается как приложение через «Добавить на главный экран».
