1. 登録と初回ログイン

最初の画面で「登録する」をタップし、メールアドレスとユーザー名を入力します。電話番号は不要です。

登録後、次の3つの情報が一度だけ表示されます。パスワードマネージャーなど安全な場所にすぐ保存してください。

  • ユーザー名とパスワード：ユーザー名が最初の入力欄で、パスワードが開くプロフィールを決めます。同じユーザー名で複数のプロフィールを持て、それぞれ別のパスワードを使います。
  • 公開ID：連絡先に追加してほしい相手と共有するものです。メールアドレスは明かされません。
  • 秘密の組み合わせ：非表示チャットを表示するために使います（専用の項目を参照）。

パスワードを失うとプロフィールにアクセスできなくなります。メールによる本格的な復旧はまだありません（「明示されたセキュリティ上の制限」を参照）。

2. 同じ端末の複数プロフィール

同じユーザー名で異なるパスワードを使い、複数のプロフィール（例：個人用とカバー用）を作成できます。ユーザー名とパスワードを入力すると対応するプロフィールが開き、プロフィール数が分かる選択画面は表示されません。同じユーザー名の2つのプロフィールに同じパスワードは使えません。

3. 連絡先の追加とチャット

「+ 連絡先を追加」をタップして相手の公開IDを入力します。エンドツーエンドで暗号化されたリアルタイムのチャットが開きます（第7項を参照）。

4. 非表示チャットと秘密の組み合わせ

チャット内でメニューを開き、「このチャットを非表示/表示」を選びます。非表示にしたチャットはメインリストに表示されなくなります。

再表示するには、検索バーに秘密の組み合わせ（登録時に一度だけ表示されたもの）を入力します。アプリを再びロックするまで、すべての非表示チャットが表示されます。

5. カバープロフィール

登録時に「カバープロフィールとして作成」を選べます。確認を受けたときに見せるためのプロフィールで、同じ端末に他のプロフィールがあることを示す手がかりは含まれません。

6. 時限メッセージ（自動消去）

メッセージを送る前に、ドロップダウンから自動消去までの時間（30秒、5分、1時間）を選べます。その時間が過ぎるとメッセージは削除されます。

7. エンドツーエンド暗号化：本当の仕組み

これは宣伝文句ではありません。すべてのメッセージは、サーバーに送信される前にお使いのブラウザ内で次の方式で暗号化されます。

  1. 初回ログイン時に、端末がP-256曲線上のECDH鍵ペア（公開鍵と秘密鍵）を生成します。公開鍵はサーバーにアップロードされ、秘密鍵はブラウザ内にだけ残ります。
  2. 連絡先にメッセージを送るとき、ブラウザはあなたの秘密鍵と相手の公開鍵を組み合わせ（ECDH交換）、HKDF-SHA256でその2人専用の256ビットAES-GCM共通鍵を導出します。
  3. 各メッセージはその鍵と、毎回異なる乱数（IV）で暗号化され、暗号化された状態でサーバーに送られます。
  4. サーバーは暗号文を保存・中継するだけで、メッセージの内容を読むことはできません。

これは多くの現代的な安全なプロトコルが使うのと同じ種類の数学（ECDH + AES-GCM）で、ここではブラウザ標準のWeb Crypto APIを使い、外部ライブラリなしで実装しています。

8. 生体認証ロック解除（Face ID / Touch ID / 指紋）

プロフィール設定（⚙️アイコン）に「Face ID / 指紋でのロック解除を有効にする」があります。有効にすると、端末がWebAuthn/FIDO2でパスキーを作成してサーバーに登録します（公開鍵のみで、生体データは決して送られません）。

以降、ログイン画面に「生体認証でロック解除」ボタンが表示されます。パスワードの代わりに使え、Face ID、Touch ID、Androidの指紋、Windows Helloの確認はアプリではなくOSが行います。生体データが端末の外に出ることはありません。

同じ設定からいつでも無効にできます。

9. 言語の切り替え

アプリの各画面の上部に言語セレクターがあります。このサイトも同じ11言語で利用できます：イタリア語、英語、スペイン語、フランス語、ドイツ語、ポルトガル語、アラビア語、中国語、ヒンディー語、ロシア語、日本語。アプリで選んだ言語は端末に記憶されます。

10. ネイティブモバイルアプリ（iOS/Android）

起動時にシステムレベルの生体認証ロックを追加する、ネイティブアプリの土台（Expo/React Nativeベース）が用意されています。App StoreとGoogle Playへの実際の公開には、開発者アカウントの認証情報（Apple Developer ProgramとGoogle Play Console）が必要です。接続後にアプリをビルドして公開できます。それまでは、ウェブアプリをどのモバイルブラウザでも使え、ホーム画面にアプリのように「インストール」できます。

11. 明示している安全性の制限

正直にお伝えすると、暗号化自体は本物ですが、このプロトタイプにはまだないものがあります。

  • ラチェット／前方秘匿性がない：チャットの鍵は、双方が鍵を再生成するまで変わりません（メッセージごとに鍵を更新するSignalのようなプロトコルとは異なります）。
  • 公開鍵の帯域外検証がない：連絡先と口頭で照合できる「セーフティナンバー」がありません。理論上、悪意あるサーバーが公開鍵を自分の鍵にすり替える（中間者攻撃）可能性があります。信頼できるサーバー上のプロトタイプなら許容できますが、高リスクな利用の前にこの検証を追加すべきです。
  • 秘密鍵がブラウザ内にある：ハードウェアのセキュアエンクレーブではなく、ブラウザのローカルストレージ（localStorage）に保存されています。ロック解除済みの端末に物理的またはソフトウェア的にアクセスできる人は、読み取れる可能性があります。
  • 本物のメール送信がない：登録は機能しますが、「マジックリンク」によるアカウント復旧のためのメールサービスはまだ接続されていません。

12. トラブルシューティング

「暗号化できません：連絡先にまだ公開鍵がありません」

連絡先がアプリの最新アップデート後にまだログインしていない場合に起こります（鍵はログイン時に自動で生成・アップロードされます）。一度ログインしてもらえば、通常どおりメッセージを送れるようになります。

「パスワードを忘れた」

現時点では自動復旧はなく、新しいプロフィールを登録する必要があります。パスワードは必ずパスワードマネージャーで保管してください。

生体認証ロック解除が表示されない

Face ID、Touch ID、指紋、またはWindows Helloが設定された端末、最新のブラウザ、HTTPS接続（本番のウェブアプリはすでに使用しています）が必要です。また、設定で少なくとも一度は有効にしておく必要があります。
