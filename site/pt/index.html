Sem número de telefone

Cada mensagem é criptografada no navegador com ECDH (P-256) + AES-GCM de 256 bits antes de sair: o servidor só vê texto cifrado, nunca o conteúdo em claro.

Face ID, Touch ID, impressão digital do Android ou Windows Hello via WebAuthn/FIDO2 real: nenhum dado biométrico sai do dispositivo.

Como funciona

Cadastre-se

E-mail e nome de usuário: você recebe um código de acesso, um ID público e uma combinação secreta. Guarde-os: não são mostrados novamente.

Entre com o código

A cada abertura, digite o código: o perfil correspondente abre automaticamente.

Adicione contatos

Procure uma pessoa pelo ID público dela e comece a conversar em tempo real.

Oculte o que quiser

Digite a combinação secreta na barra de busca para revelar os chats ocultos quando precisar.

O que é e o que não é

Este é um protótipo funcional, não um produto acabado. As mensagens têm criptografia de ponta a ponta (ECDH P-256 + AES-GCM de 256 bits, derivação HKDF-SHA256): o servidor nunca vê o texto em claro. O desbloqueio biométrico usa WebAuthn/FIDO2 real. Permanecem limites conhecidos, explicados sem rodeios no manual do usuário: ainda não há um ratchet com forward secrecy "à la Signal", não há verificação fora de banda das chaves públicas (em teoria, um servidor malicioso poderia substituí-las), a chave privada fica no navegador sem enclave seguro de hardware e o envio real de e-mails para recuperação de conta ainda não está ligado. Útil para experimentar o uso com segurança real, mas não "à prova de Estado" — ainda não para conversas de altíssimo risco.

Apps nativos para iOS e Android

A base do app nativo (Expo/React Native, com bloqueio biométrico do sistema) está pronta no código do projeto. A publicação na App Store e no Google Play exige as credenciais das contas de desenvolvedor (Apple Developer Program e Google Play Console): até serem ligadas, o app continua disponível como aplicação web, utilizável em qualquer navegador móvel e já instalável como app em "Adicionar à tela inicial".
